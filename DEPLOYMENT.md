# Bark Nibbles Inventory deployment

For installation, admin setup, Wi-Fi access, database backup, security limitations, and troubleshooting, see the [User Guidelines](./USER-GUIDELINES.md).

The Windows x64 package `Bark-Nibbles-Inventory-Windows-x64.zip` contains a snapshot of the local database and its business data. Distribute it only through an authorized, secure channel (such as a private GitHub Release); do not publish it publicly or commit it to the source repository. See the [User Guidelines](./USER-GUIDELINES.md) for installation, database, and security details. The project overview and development instructions are in the [README](./README.md).
