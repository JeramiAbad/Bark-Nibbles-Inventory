# Bark Nibbles Inventory deployment

For installation, admin setup, Wi-Fi access, database backup, security limitations, and troubleshooting, see the [User Guidelines](./USER-GUIDELINES.md).

The public-safe Windows x64 package is `dist/Bark-Nibbles-Inventory-Windows-x64-No-Database.zip`. It has no database; the app creates a fresh one and seeds the starter catalog on first run. Never commit or publicly distribute `inventory.db` or an archive containing it. A separate package containing business records must be shared only through an authorized, secure channel. See the [User Guidelines](./USER-GUIDELINES.md) for installation, database, and security details. The project overview and development instructions are in the [README](./README.md).
